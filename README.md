# 🚀 LeetCodeRush

### A daily journey to build consistency, master DSA, and become a better problem solver.

Welcome to **LeetCodeRush** — my personal journey of solving LeetCode problems consistently while learning and strengthening my **Data Structures and Algorithms (DSA)** skills.

This repository isn't just a collection of solutions. It's a record of my **daily effort, learning, mistakes, improvements, and progress**.

---

## 🎯 Why I Created LeetCodeRush

I created **LeetCodeRush** to make DSA practice a consistent part of my daily routine.

It's easy to solve a few problems, take a break, and lose momentum. The goal of this repository is to change that by showing up **every day**, solving problems, learning new concepts, and gradually becoming better.

> **Consistency over intensity. One problem at a time.**

Through this journey, I aim to:

* 🧠 Strengthen my understanding of **Data Structures & Algorithms**
* 🔥 Build a sustainable **daily coding habit**
* 💡 Improve logical and problem-solving skills
* 🎯 Prepare for **technical interviews**
* 🏆 Become more confident with unfamiliar problems
* 📈 Track my progress and improvement over time
* 🚀 Eventually move towards stronger **competitive programming** skills
